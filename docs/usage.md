# 使い方

## ウィンドウ

ウィンドウのサイズ・位置・最大化状態は次回起動時に復元します。外部ディスプレイを外した場合は、現在の画面内に収まる位置へ調整します。開発時の保存先は `.runtime/window-state.json` です。

## フォルダーとファイル

- 左サイドバー上部の **フォルダー設定** から、既存の `.hs` があるフォルダーを選択できます。選んだフォルダーは次回起動時にも開きます。
- 選択したフォルダーの **直下** にある通常の `.hs` ファイルを表示します。サブフォルダー・シンボリックリンクは一覧に含めません。
- 一覧には実ファイル名と **更新日** を表示し、更新日時の新しい順に並べます。フォルダー内の追加・削除・保存も一覧に反映します。ファイル名で検索できます。
- **＋ 新しいファイル** で名前を指定すると、そのフォルダーへ直接作成します。`.hs` を省略した場合は自動で付けます。同名ファイルは上書きしません。
- 保存する内容は **`.hs` ソースだけ** です。コードのスナップショット、`index.json`、`revisions.json`、会話履歴のファイルは作りません。安全な上書き用の一時ファイルは保存完了時に取り除きます。
- 自動保存は行いません。`⌘S`・`Ctrl+S`・`:w`・保存ボタンで同じ `.hs` を保存します。GHCiでの読込／再読込時にも保存します。編集待ち・フォーカス移動・AIチャット送信では保存しません。未保存のままファイルやフォルダーを切り替える場合やアプリを終了する場合は、変更を破棄するか確認します。キャンセルすると編集を続けられます。変更のない保存ではファイルの更新日時を変えません。
- エディタのタブ行にあるフォルダーアイコンで、編集中のファイルをFinderなどで表示できます。

初期フォルダーは、このプロジェクトの `workspace/` です。任意のフォルダーへ変更できます。

```text
選択したフォルダー/
  Solution.hs
  SumOfOddNumbers.hs
  AnotherKata.hs
```

フォルダー選択などのアプリ設定は、ソースフォルダーとは別のElectron設定領域に保存します。開発時は `.runtime/workspace.json` です。
旧バージョンのID別フォルダー形式がある場合は、起動時にそのコードを名前付きの `.hs` として引き継ぎます。既存ファイルは上書きせず、元のコード・管理情報はアプリ設定領域の `legacy-workspace-*` に退避します。

## エディタとGHCi

CodeMirror 6のHaskellハイライト、行番号、検索、括弧補完に対応しています。Vimは初期状態で有効です。`i` で挿入、`Esc` でノーマル、`:w` で保存。Vimスイッチで通常の編集にも切り替えられます。

編集中のファイルに存在する単語だけを使って入力を補完します。関数名・変数名、文字列・コメント内の単語、日本語、末尾に `'` の付いたHaskellの識別子も候補になります。入力中に候補を自動表示し、Ctrl+Spaceでも呼び出せます。上下キーで選択し、TabまたはEnterで確定します。候補がない場合のTabは通常のインデントです。Vimでは挿入モードで有効で、Escは候補を閉じてノーマルモードへ戻ります。別のファイルや外部サービスから候補を取得しません。

画面右上の **エディタ設定（Tアイコン）** から、システム標準・JetBrains Mono・Fira Code・Hasklig・Monaspace Neon・Monaspace Argonを選択できます。文字サイズ（10〜28px）、行間、合字も調整できます。Haskellコードのプレビューとエディタへ即時反映し、設定は次回起動時にも引き継ぎます。「標準に戻す」でフォントと配色を初期設定に戻せます。追加フォントはアプリに同梱するため、OSへのインストールや起動時のインターネット接続は不要です。日本語は環境のフォントで補完します。GHCiのターミナルのフォントは従来どおりです。

同じ画面の **配色テーマ** で、Kata Light（標準）・Catppuccin Latte・Rosé Pine Dawn・Solarized Lightを選べます。いずれも明るい背景のテーマです。エディタとプレビューの背景・行番号・選択色・構文色へ即時反映し、コードやUndo履歴を保持したまま切り替えられます。配色は次回起動時にも復元し、サイドバー・GHCi・AIアシスタントの配色は変更しません。Haskellの組み込み関数、型、演算子を分類し、それぞれテーマの色を適用しています。

ファイルを開くだけではGHCiを起動しません。「読込」または⌘Enterで、そのファイル専用のGHCiを疑似端末（PTY）で起動し、ファイルを読み込みます。既に起動している場合は同じセッションで再読み込みします。ファイルを切り替えて戻った場合は、既存の端末表示だけを復元します。端末はxterm.jsで表示します。入力欄やプロンプト、コマンド履歴はGHCi本来のものです。Tab補完、上下キーの履歴、Ctrl+C、`:quit`、`:t`、`:info`、`:{` / `:}` による複数行入力を使えます。`getLine` の対話入力にも対応します。エディタと下部パネルの間のハンドルで高さを調整できます。下部はGHCi専用です。左右のサイドバーは中央との境界をドラッグして幅を調整でき、調整した幅は次回起動時にも引き継ぎます。境界にフォーカスして左右キーでも調整できます。幅を変えてもGHCiのセッションや入力中の式は保持します。

GHCiヘッダーの「読込／再読込」または ⌘Enter は未保存の編集を保存します。未起動ならGHCiを起動してファイルを読み込み、起動済みならCtrl+Cで現在の入力・計算を中断して `:reload` を送ります。端末での通常の式入力にはアプリ側の処理を挟みません。計算の時間制限も設けていません。終了後は ↻ で再起動できます。最大6ファイルの端末セッションを保持し、それを超えたときは古いセッションから終了します。

## GHCiのエラーと行ごとのAI説明

エディタ上部の「GHCi読込」、GHCiヘッダーの「読込／再読込」、または **⌘Enter**（Windows/LinuxはCtrl+Enter）で保存してGHCiへ読み込みます。⌘⇧Enter（Ctrl+Shift+Enter）も同じ操作です。独立したGHCコンパイルは実行しません。

読み込み・エラー解析の進捗は画面右下のポップアップに表示します。完了後は自動で消え、×でも閉じられます。読み込みに失敗した場合、GHCiの診断を該当行の横に表示します。その後、裏でCodexエージェントが原因と修正箇所の行番号を解析し、AIが指定した行の横に短い日本語の説明を表示します。表示先はGHCiの報告行と異なる場合があります。説明は複数行に折り返して全文を表示します。マウスを重ねると元の診断も確認できます。元の出力はGHCiターミナルで確認できます。端末に直接入力した式のエラーも自動解析します。実行時例外や別ファイルのエラーなど、編集中の行に対応しない診断はポップアップに説明を表示し、行番号を推測しません。

解析ではAIアシスタントを開かず、チャット履歴にも追加しません。モデルと推論レベルは設定済みの選択を使います。解析専用の一時スレッドで構造化JSONを取得し、エラー番号を検証して説明だけを表示します。AIが利用できないときも元のGHCi診断は残ります。コードを編集しても説明は残り、行の追加・削除に追従します。手動保存またはGHCiへの再読み込みで消え、再読み込み後のエラー解析で更新します。解析結果はメモリ上だけに保持します。

「エラーを解析」またはCtrl+J → eで、直近のGHCiエラーを裏で再解析できます。コードを変更していた場合は、先にGHCiへ再読み込みしてください。

## AI相談

右サイドバーの「AIアシスタント」にチャット履歴と一行の入力欄を表示します。Enterまたは送信ボタンで質問し、応答中は停止ボタンで中断できます。ファイルを開くと既存のCodexログインでapp-serverへ自動接続し、AIアシスタント上部でモデルと推論レベルを選べます。右上のボタンで開閉でき、閉じたときは右端のボタンで再表示できます。開閉状態は次回起動時にも引き継ぎます。選択肢は接続先の `model/list` から取得し、そのモデルが対応する推論レベルだけを表示します。選択は次回起動時にも引き継ぎ、次の質問から適用します。選択したモデルが利用できなくなった場合は、接続先の既定モデルに戻ります。

質問送信時に未保存の編集を含む現在のコードを添付し、回答をストリーミング表示します。GHCiのエラー解析はこのチャットとは別の経路で行い、チャット履歴に追加しません。

PTYの出力では標準出力と標準エラーが混ざりますが、その出力自体は取得できます。色などの端末制御コードを除き、GHCの診断形式や `*** Exception:` を検知します。診断の自動判定は形式に依存します。出力・診断はメモリ上だけで扱い、ソースフォルダーにログファイルは作りません。

AIは組み込みWeb検索でインターネットを検索でき、Webの情報を使うときは出典を回答に付けます。このアプリの接続とスレッドに `web_search = "live"` を指定し、ユーザー共通のCodex設定ファイルは変更しません。ファイルは読み取り専用で、コマンド実行用のシェルツールは無効にしています。修正コードは回答から手動で反映します。会話はファイルごとに、この起動セッション中だけ保持します。フォルダー切替・アプリ終了後に会話は引き継ぎません。

## ショートカット

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 新しいファイル | ⌘N | Ctrl+N |
| 保存 | ⌘S / `:w` | Ctrl+S / `:w` |
| GHCi起動・読込／再読込・エラー解析 | ⌘Enter / ⌘⇧Enter | Ctrl+Enter / Ctrl+Shift+Enter |
| GHCi入力欄へ | ⌘J | Ctrl+Shift+J |
| ファイル内の単語で補完 | Ctrl+Space | Ctrl+Space |
| 領域のフォーカスを左 / 下 / 上 / 右へ | Ctrl+J → h / j / k / l | Ctrl+J → h / j / k / l |
| GHCiのエラーを裏で再解析 | Ctrl+J → e | Ctrl+J → e |
| GHCi実行を中断 | Ctrl+C（端末内） | Ctrl+C（端末内） |
| ヘルプ | ⌘/ | Ctrl+/ |

Ctrl+Jを押してから2秒以内にeを押すと、検知したGHCiのエラーを裏で再解析します。エディタ・GHCi・左右のサイドバーから使えます。エラーがない場合や、そのファイルの読み込み・解析中は送信しません。チャットは開きません。

Ctrl+Jを押してから2秒以内にh/j/k/lを押すと領域を移動します。Controlを押したまま方向キーを入力することもできます。エディタから下（j）でGHCi、GHCiから上（k）でエディタへ移動します。エディタ・GHCiから右（l）でAIアシスタントへ移り、左（h）で元の領域へ戻ります。AIサイドバーが閉じていれば開いて移動します。左サイドバーへの移動にも対応します。移動先がない方向ではフォーカスを変えません。Escで待機を解除できます。Ctrl+Jは端末へ送らないため、この操作でGHCiの式は実行されません。
