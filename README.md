# Kata — Haskell workspace

小さなHaskellの問題を解くための、Electron製デスクトップIDEです。
左にファイル一覧、中央にVim対応エディタとGHCi、右にCodexとの会話を配置しています。

## 起動

Node.js 20.19+（22系は22.12+）、GHC/GHCi、Codex CLIを用意してください。

```sh
./start.sh
```

初回は依存パッケージを自動インストールし、ビルドしてElectronを起動します。別のディレクトリから絶対パスで実行することもできます。開発時は `npm run dev` で起動できます。
AIを使う前に、未ログインの場合はターミナルで `codex login` を実行してください。

## フォルダーとファイル

- 左サイドバー上部の **フォルダー設定** から、既存の `.hs` があるフォルダーを選択できます。選んだフォルダーは次回起動時にも開きます。
- 選択したフォルダーの **直下** にある通常の `.hs` ファイルを表示します。サブフォルダー・シンボリックリンクは一覧に含めません。
- 一覧には実ファイル名と **更新日** を表示し、更新日時の新しい順に並べます。フォルダー内の追加・削除・保存も一覧に反映します。ファイル名で検索できます。
- **＋ 新しいファイル** で名前を指定すると、そのフォルダーへ直接作成します。`.hs` を省略した場合は自動で付けます。同名ファイルは上書きしません。
- 保存する内容は **`.hs` ソースだけ** です。コードのスナップショット、`index.json`、`revisions.json`、会話履歴のファイルは作りません。安全な上書き用の一時ファイルは保存完了時に取り除きます。
- 編集の700ms後に自動保存します。`⌘S`・`:w` でも同じ `.hs` を保存します。変更のない保存ではファイルの更新日時を変えません。
- エディタのタブ行にあるフォルダーアイコンで、編集中のファイルをFinderなどで表示できます。

初期フォルダーは、このプロジェクトの `workspace/` です。任意のフォルダーへ変更できます。

```text
選択したフォルダー/
  Solution.hs
  SumOfOddNumbers.hs
  AnotherKata.hs
```

フォルダー選択などのアプリ設定は、ソースフォルダーとは別のElectron設定領域に保存します。開発時は `.runtime/workspace.json` です。
旧バージョンのID別フォルダー形式がある場合は、起動時にそのコードを名前付きの `.hs` として引き継ぎます。既存ファイルは上書きせず、元のコード・管理情報はアプリ設定領域の `legacy-workspace-*` に退避します。

## エディタとGHCi

CodeMirror 6のHaskellハイライト、行番号、検索、括弧補完に対応しています。Vimは初期状態で有効です。`i` で挿入、`Esc` でノーマル、`:w` で保存。Vimスイッチで通常の編集にも切り替えられます。

ファイルを開くと専用のGHCiプロセスを起動し、そのファイルをロードします。下の入力欄で式や `:t`、`:info` などを実行できます。実行前に未保存の編集を保存し、ファイルを再読込します。Shift+Enterで複数行入力、上下キーでこのセッション中のコマンド履歴を移動できます。エディタとGHCiの間のハンドルで高さを調整できます。

GHCiはパイプ接続です。TTYが必要なプログラムや `getLine` を使う対話入出力には対応していません。60秒で応答しない計算はプロセスを停止します。停止ボタンでも中断でき、再起動ボタンで復旧できます。待機中の古いセッションから最大6プロセスに整理します。

## AI相談

右の「Codex に接続」でapp-serverへ接続できます。初めて送信するときにも自動接続します。既存のCodexログインを利用し、接続後にモデルを選択できます。

質問送信時に現在のコードを添付し、回答をストリーミング表示します。GHCiの「エラーをAIに聞く」で、実行式・エラー入りの質問を作れます。内容を確認・編集して送信してください。

AIは読み取り専用のチューターとして動作し、修正コードは回答から手動で反映します。会話はファイルごとに、この起動セッション中だけ保持します。フォルダー切替・アプリ終了後に会話は引き継ぎません。

## ショートカット

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 新しいファイル | ⌘N | Ctrl+N |
| 保存 | ⌘S / `:w` | Ctrl+S / `:w` |
| 保存してGHCi再読込 | ⌘Enter | Ctrl+Enter |
| GHCi入力欄へ | ⌘J | Ctrl+J |
| GHCi実行を中断 | Ctrl+C（GHCi入力欄） | Ctrl+C（GHCi入力欄） |
| ヘルプ | ⌘/ | Ctrl+/ |

## 環境変数

| 変数 | 用途 |
| --- | --- |
| `KATA_WORKSPACE` | 起動時に開くフォルダー（保存済みの選択より優先） |
| `KATA_GHCI` | GHCi実行ファイルのパス |
| `KATA_CODEX` | Codex CLI実行ファイルのパス |
| `KATA_RUNTIME` | 開発中のElectron設定・キャッシュ保存先 |

## 検証

```sh
npm test                # ファイル操作・フォルダー設定・移行・実GHCi・Codex通信
npm run build           # TypeScriptチェックとproductionビルド
npm run test:electron   # GUIを起動できる環境でElectronの操作テスト
```

通常のテストでは、既存 `.hs` の読み込み、更新日時順、直接保存、同名ファイルの保護、フォルダー設定の記憶、旧形式からの移行を確認します。GHCiは実際のプロセスで動作を確認し、Codexの回答生成はテスト用app-serverで検証します。
今回の環境では、権限制限によりElectronの画面・ネイティブのフォルダー選択ダイアログ・実AI回答の確認はできていません。

実装参照: [公式Codex app-serverドキュメント](https://developers.openai.com/codex/app-server)。
